# Changelog

## 1.0.0-alpha — 2026-10-31

- Sanitized, general-purpose community toolkit based on a single successful field migration.
- Read-only exporters for legacy privileges and target site identity checks.
- Generic Excel schema with explicit legacy-username mapping and manual-Super-Admin mode.
- Offline validation, single-user and batch API import, durable pre-POST checkpoints.
- CSRF in same-origin Chrome session, no plaintext secrets in logs.
- Synthetic offline tests; no vendor API compatibility guarantee.
